# 1. PROJECT IDENTITY

## 1.1 Project name

**PHOBOSIA**

## 1.2 Project category

- Interactive 3D Mars exploration experience.
- Browser-based 3D environment.
- Scientific observation-themed exploration game.
- Educational space exploration experience.
- Mission-driven interactive project.

## 1.3 Main project description

PHOBOSIA is an immersive, browser-based 3D Mars exploration experience that allows users to explore a fictional Martian outpost, interact with its operational environments, and participate in a sequence of scientific observation missions.

The experience combines a custom-built 3D Mars environment, interactive outpost modules, physical console interfaces, mission objectives, and exploration activities to create a more engaging way to experience the concepts of planetary exploration.

Rather than presenting Mars as a static collection of facts or images, PHOBOSIA places the user inside an interactive environment where they can explore different areas, operate existing systems, review mission information, and progress through a structured expedition.

## 1.4 Short project description

PHOBOSIA is a browser-based 3D Mars exploration experience focused on interactive scientific observation, outpost exploration, and mission-driven discovery.

## 1.5 Suggested project tagline

**Explore Beyond Earth. Discover the Red Planet.**

Alternative supporting phrase:

**An Interactive Journey Through Mars Exploration and Scientific Observation.**

# 2. PROJECT PURPOSE AND VISION

## 2.1 Why PHOBOSIA was created

The main idea behind PHOBOSIA is to make Mars exploration more engaging through an interactive 3D environment.

Traditional educational resources often present planetary science through text, photographs, diagrams, and videos.

PHOBOSIA explores a different approach.

It places users inside a fictional Mars outpost where they can experience the environment from a first-person perspective and interact with different operational and scientific areas.

The project aims to connect:

- Interactive 3D technology.
- Planetary exploration.
- Scientific observation.
- Space research concepts.
- Mission-based learning.
- Environmental and habitat systems.
- Digital storytelling.

## 2.2 Main objectives

The project's main objectives are:

1. Create an immersive browser-based Mars exploration environment.
2. Represent a fictional Martian outpost through custom 3D environments.
3. Introduce users to different areas of a Mars research outpost.
4. Provide interactive physical screens and operational interfaces.
5. Present scientific observation through structured missions.
6. Encourage users to investigate and understand planetary exploration concepts.
7. Demonstrate how browser-based 3D technology can support educational and exploratory experiences.

## 2.3 What makes PHOBOSIA different?

PHOBOSIA is not simply a static Mars visualization.

Its distinguishing elements include:

- A navigable first-person 3D environment.
- Multiple interconnected outpost sections.
- Custom-created 3D models.
- Interactive physical consoles.
- Mission-specific information and records.
- A structured SOL 1–11 campaign.
- Mars terrain based on a selected real-world Martian location, subject to source verification.
- A fictional astronaut narrative.
- A browser-based experience that does not require a conventional desktop game installation, subject to actual deployment behavior.

Explain these points with appropriate screenshots and project imagery.
